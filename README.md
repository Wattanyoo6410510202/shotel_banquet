# ระบบขอใบเสนอราคางานจัดเลี้ยง

เว็บมี 2 ส่วน

| ส่วน | ใครใช้ | เปิดที่ |
|---|---|---|
| **หน้าบ้าน** | ลูกค้า — กรอกฟอร์ม เลือกอาหาร ส่งคำขอ | `http://localhost/shotel_banquet/` |
| **หลังบ้าน** | พนักงาน — ดูรายการที่ลูกค้าส่งมา แก้ไข พิมพ์ใบเสนอราคา | `http://localhost/shotel_banquet/admin/` |

## วิธีติดตั้ง

### ขั้นที่ 1 — สร้างตารางในฐานข้อมูล
1. เข้า [supabase.com](https://supabase.com) → เลือกโปรเจกต์
2. เมนูซ้าย **SQL Editor** → กด **New query**
3. คัดลอกทั้งหมดในไฟล์ `supabase/schema.sql` ไปวาง → กด **Run**
4. (ถ้าต้องการเมนูตัวอย่าง) ทำซ้ำกับไฟล์ `supabase/seed.sql`

> รันซ้ำได้ ข้อมูลเดิมไม่หาย

### ขั้นที่ 2 — ปิดการสมัครสมาชิก และสร้างบัญชีพนักงาน
1. เมนูซ้าย **Authentication** → **Sign In / Providers**
   → ปิดสวิตช์ **Allow new users to sign up** → Save
   > ⚠️ สำคัญมาก ถ้าไม่ปิด คนนอกจะสมัครแล้วเข้าไปดูข้อมูลลูกค้าในหลังบ้านได้
2. **Authentication** → **Users** → **Add user** → **Create new user**
   → ใส่อีเมลและรหัสผ่านของพนักงาน → ติ๊ก **Auto Confirm User** → Create

### ขั้นที่ 3 — ใส่รหัสเชื่อมต่อในไฟล์ `config.js`
1. **Project Settings** → **API Keys** → คัดลอก **Publishable key** (ขึ้นต้นด้วย `sb_publishable_...`)
2. เปิดไฟล์ `config.js` แล้ววางแทน `YOUR_ANON_KEY`

```js
window.APP_CONFIG = {
  SUPABASE_URL: 'https://govmturozgtfvllvnvap.supabase.co',
  SUPABASE_ANON_KEY: 'sb_publishable_...',
};
```

> Publishable key ใส่ในหน้าเว็บได้ปลอดภัย (ถ้าโปรเจกต์เป็นแบบเก่า ใช้ **anon public** แทนได้)
> **ห้าม** ใส่ **Secret key**, `service_role` หรือรหัสผ่านฐานข้อมูลในไฟล์นี้

### ขั้นที่ 4 — เปิดใช้งาน
- เปิดโปรแกรม XAMPP → กด Start ที่ Apache
- หน้าบ้าน: `http://localhost/shotel_banquet/`
- หลังบ้าน: `http://localhost/shotel_banquet/admin/`

> ต้องเปิดผ่าน `http://localhost/...` เท่านั้น ถ้าดับเบิลคลิกไฟล์เปิดตรงๆ จะใช้งานไม่ได้

## การใช้งาน

### ลูกค้า (หน้าบ้าน)
1. เลือกประเภทงาน วันที่ จำนวนแขก
2. เลือกอาหาร — มีทั้งแบบ **แพ็กเกจ** (เช่น โต๊ะจีน/ชุดไทย เลือกเมนูแต่ละคอร์สเอง) และเมนูเสริมทีละจาน
   ด้านล่างจอแสดงราคาโดยประมาณ (แพ็กเกจที่ยังเลือกไม่ครบทุกคอร์สจะยังไม่รวมราคา)
3. กรอกชื่อ เบอร์โทร ติ๊กยินยอม → **ส่งคำขอ**
4. ได้เลขที่คำขอ + ใบเสนอราคาเบื้องต้น พิมพ์ได้ และเก็บลิงก์ไว้ดูสถานะภายหลังได้

### พนักงาน (หลังบ้าน)
1. **ตั้งค่า** — ใส่ชื่อโรงแรม ที่อยู่ โลโก้ เงื่อนไข ข้อความต้อนรับ และเปิด/ปิดรับคำขอ
2. **เมนูอาหาร** — เพิ่ม แก้ไข ปิดใช้งานเมนู
   - แต่ละเมนู/แพ็กเกจใส่รูปภาพได้ — อัปโหลดไฟล์ได้เลย (ไม่เกิน 5MB) หรือใส่ URL ภายนอกก็ได้
   - **นำเข้า/ส่งออก CSV** ได้ทั้งชุด — กด "ส่งออก CSV" เพื่อได้ไฟล์ปัจจุบันไปแก้ราคาใน Excel แล้วกด "นำเข้า CSV" กลับเข้ามา
     (แถวไหนใส่ `id` มา = แก้ไขของเดิม, `id` ว่าง = เพิ่มใหม่, หมวดหมู่ที่ยังไม่มีจะถูกสร้างให้อัตโนมัติ)
3. **แพ็กเกจ** — จัดการชุดโต๊ะจีน/ชุดไทย: ตั้งราคา, เพิ่ม/ลบคอร์ส, กำหนดเลือกได้กี่อย่างต่อคอร์ส (`pick_count`),
   เลือกเมนูเข้าคอร์ส (ดึงจากคลังเมนูทั้งหมด ไม่ต้องเปิดขายเดี่ยวก็ใช้ในแพ็กเกจได้)
4. **รายการที่บันทึก** — คำขอใหม่จากลูกค้าจะมีแถบสีเหลือง
   - กด **ดู** → โทรหาลูกค้า, คัดลอกลิงก์ส่งให้ลูกค้า, พิมพ์
   - กด **แก้ไข** → ปรับราคา จำนวน ส่วนลด ใส่ห้อง เพิ่มรายการอื่นๆ หรือกด **+ แพ็กเกจ** เพื่อเพิ่มชุดโต๊ะจีน/ชุดไทยแบบเลือกคอร์สได้เหมือนหน้าบ้าน
   - เปลี่ยนสถานะ: คำขอใหม่ → ฉบับร่าง → ส่งลูกค้าแล้ว → ยืนยันแล้ว
5. **พิมพ์ / บันทึก PDF** — เลือก "Save as PDF" และปิด "Headers and footers"

## หน้าตาเว็บ
- **ใช้บนมือถือได้ทั้งหน้าบ้านและหลังบ้าน** — ตารางในหลังบ้านจะเปลี่ยนเป็นการ์ดเมื่อจอแคบ
- **ธีมสว่าง / มืด** — กดปุ่ม 🌙 / ☀️ มุมขวาบน ค่าเริ่มต้นตามการตั้งค่าของเครื่อง และจำค่าที่เลือกไว้
  ใบเสนอราคาเป็นพื้นขาวเสมอ เพื่อให้พิมพ์ออกมาสวย
- **โลโก้** — ไฟล์ `assets/img/logo.png` ใช้เป็นไอคอนแท็บ หัวเว็บ และในใบเสนอราคา
  ถ้าต้องการเปลี่ยน ให้แทนที่ไฟล์นี้ (สี่เหลี่ยมจัตุรัส) หรือใส่ "URL โลโก้" ในหน้าตั้งค่า

## เมื่อแก้ไขไฟล์ CSS / JS
ในหน้า HTML ลิงก์ไฟล์จะมีเลขเวอร์ชันต่อท้าย เช่น `core.js?v=2`
เมื่อแก้ไฟล์ในโฟลเดอร์ `assets/` ให้เปลี่ยนเลขนี้ในทุกหน้า (เช่น `?v=3`) ไม่งั้นเบราว์เซอร์ของลูกค้าอาจยังใช้ไฟล์เก่า

## รูปภาพเมนู
เก็บในที่เก็บไฟล์ของ Supabase (bucket ชื่อ `menu-images`) — อัปโหลดได้จากหน้า "เมนูอาหาร" และ "แพ็กเกจ"
ไฟล์ที่อัปโหลดดูได้สาธารณะ (จำเป็น เพราะลูกค้าไม่ได้ล็อกอิน) แต่อัปโหลด/ลบได้เฉพาะพนักงานที่ล็อกอินแล้ว
รองรับ JPG/PNG/WEBP/GIF ไม่เกิน 5MB ต่อไฟล์ — ไฟล์เก่าที่แทนที่ด้วยรูปใหม่จะไม่ถูกลบอัตโนมัติ ถ้าต้องการเคลียร์พื้นที่ ลบเองได้ที่ Supabase Dashboard → Storage

## ความปลอดภัยที่มีในระบบ
- ลูกค้า **แก้ราคาเองไม่ได้** ระบบดึงราคาจากเมนูในฐานข้อมูลทุกครั้ง
- ลูกค้าดูได้เฉพาะคำขอของตัวเองผ่านลิงก์ส่วนตัว ดูของคนอื่นไม่ได้
- หมายเหตุภายในของพนักงาน ลูกค้าไม่เห็น
- กันส่งถี่: เบอร์เดียวกันส่งได้ไม่เกิน 5 ครั้งต่อชั่วโมง + มีช่องดักบอท

```
assets/js/core.js        ใช้ร่วม: เชื่อมฐานข้อมูล, จัดรูปแบบเงิน/วันที่ไทย, คำนวณราคา

supabase/seed.sql        เมนูตัวอย่าง
```
